# Joy Health – Dashboard Revision Request

## Screen 1: Operations Command Center (Revision)

### Goal
Revise the current dashboard. It should be an Operations Command Center, not a generic SaaS dashboard.

## Changes Required

1. Reduce AI presence.
- Move Joy Suggestions to the bottom.
- AI supports the user and never dominates the page.

2. Replace hero section.
- Remove oversized greeting.
- Compact header:
  - Today's Operations
  - Current Date
  - Search
  - Notifications
  - Profile
  - Quick Add

3. Use a three-column layout.

Left:
- Today's Schedule
- Admissions

Center:
- Employee Tasks
- Compliance
- Recent Activity

Right:
- Quick Actions
- Payroll
- Billing
- Mini Calendar

4. Add a Priority Strip.
- Open Shifts
- Assessments Today
- Orientations
- Payroll Due
- Billing Due
- Supervisor Visits

5. Today's Schedule should be agenda style.

6. Admissions card:
- New Referrals
- Phone Intakes
- Assessments Scheduled
- Pre-Onboarding
- Ready for Admission

7. Employee Tasks:
- Orientation
- Field Orientation
- Week One
- Supervisor Visits
- Annual Reviews
- Compliance

8. Replace single Quick Action button with:
- New Client
- New Employee
- Schedule Assessment
- Create Shift
- Run Payroll
- Billing Review

9. Payroll card:
- Next Export
- Submit to Gusto
- Pending Reviews

10. Billing card:
- Current Billing Week
- Billing Audit
- Ready to Invoice

11. Compliance:
- CPR
- TB
- Insurance
- Background Checks

12. Recent Activity:
Timeline only.

## Design Rules

Do NOT include:
- Revenue charts
- Pie charts
- Marketing metrics
- Executive KPIs
- Large AI banners

## Brand

Primary Color: #1407A2

Use calm spacing, rounded cards, soft shadows, and minimal clutter.

Think Apple + Linear + Notion + CareSwitch.

Design each section as a reusable widget for future drag-and-drop support.
